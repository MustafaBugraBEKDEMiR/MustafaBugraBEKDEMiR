### Hi, I'm Mustafa Buğra Bekdemir 👋

Geomatics engineer (Hacettepe University) and M.Sc. student in **Management Information Systems**
at Ankara Yıldırım Beyazıt University, based in Ankara.

I build **spatial data systems with real, open data**: PostGIS databases, routing and accessibility
analysis, web maps and small decision-support tools. Most of my work sits where geomatics meets
information systems: questions about places, answered with data you can check.

#### Tools I work with

**Spatial:** PostGIS · pgRouting · QGIS · GDAL/OGR · GeoPandas · Shapely · pyproj · osmium · Leaflet<br>
**Data & backend:** Python · SQL (PostgreSQL) · Django · REST APIs · pandas · NumPy<br>
**Engineering:** Docker · GitHub Actions · automated tests · reproducible data pipelines<br>
**Geodesy:** GNSS · reference frames & transformations · geoid modelling

#### What I care about in a project

* **Real data, stated limits.** Every repository lists its sources, licences and known limitations.
* **Reproducible.** One command (`docker compose up`) rebuilds the result; tests pin the numbers.
* **A clear question.** Each project answers one decision question that a non-specialist can understand.
